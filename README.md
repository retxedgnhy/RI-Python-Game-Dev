
# 🐱 Cat & Mouse: Open Arena Edition

A fast-paced, fail-proof 2D arcade game built in Python using **Pygame**. Navigate your mouse through open arenas, dodge the computer-controlled cat, use your tactical stun, and race diagonally across the map to reach the glowing green exit portal!

---

## 🎮 Features

* **Open Arena Layouts**: 5 custom levels featuring scattered obstacle pillars and open fields without tight, dead-end mazes.
* **Diagonal Objective**: Start as the Mouse in the top-left corner and race diagonally across the field to reach the Exit (`E`) in the bottom-right.
* **Intelligent Cat**: The cat aggressively tracks your position, getting progressively faster with each level.
* **Stun Mechanic**: Press **Spacebar** to stun the cat for 2 seconds (with a 5-second cooldown indicator and visual "ZZZ" status).
* **Heart System (Lives)**: Start with 5 hearts ❤️. Losing a heart resets your position. Hit 0 hearts for a Game Over screen.
* **Arcade Timer**: A 7-minute level timer that resets upon expiration so you can keep playing without frustration.
* **Sleek Dark Mode**: Easy-on-the-eyes dark charcoal theme with vibrant neon accents.

---

## 🚀 Getting Started

### Prerequisites
Make sure you have Python installed on your system along with the Pygame library.

```bash
pip install pygame

```

### Running the Game

1. Save the game code into a file named `game.py`.
2. Run the game from your terminal or command prompt:

```bash
python game.py

```

---

## 🕹️ Controls

| Key | Action |
| --- | --- |
| **W, A, S, D** | Move the Mouse |
| **SPACEBAR** | Stun the Cat (Duration: 2s, Cooldown: 5s) |
| **R** | Restart (on Game Over or Win screen) |

---

## 🗺️ Game Progression

* **Levels 1 - 5**: Progress through increasingly challenging open arenas with unique pillar placements and faster cat speeds.
* **Win Condition**: Successfully reach the Green Exit Portal on all 5 levels to beat the game!
